
# Titik Temu

**Titik Temu** adalah prototype aplikasi berbasis web yang dirancang untuk membantu kelompok mengambil keputusan bersama secara lebih terstruktur, transparan, dan adil.

Melalui Titik Temu, anggota kelompok dapat membuat ruang diskusi, bergabung menggunakan PIN, serta berdiskusi sebelum menentukan alternatif keputusan bersama.

## ✨ Fitur Prototype

- **Login & Register** — Tampilan masuk dan pembuatan akun.
- **Dashboard** — Halaman utama untuk mengelola ruang keputusan.
- **Buat Ruang** — Membuat ruang diskusi baru. Pembuat ruang otomatis menjadi fasilitator.
- **Gabung Ruang** — Bergabung ke ruang menggunakan PIN undangan.
- **Ruang Diskusi** — Menampilkan informasi ruang, daftar anggota, dan percakapan.
- **Undang Anggota** — Membagikan PIN agar anggota lain dapat bergabung.
- **Kontrol Fasilitator** — Menyediakan kontrol pengelolaan ruang.

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript

## 🚀 Cara Menjalankan

1. Clone repository ini:

   ```bash
   git clone https://github.com/zahrotulm-s/web-titik-temu.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd web-titik-temu
   ```

3. Buka file `index.html` menggunakan browser.

Tidak memerlukan instalasi tambahan.

## 📌 Status Proyek

Prototype / UI Demo

Proyek ini masih berupa prototype frontend. Fitur autentikasi, database, dan komunikasi antaranggota secara real-time belum terhubung ke backend.

## 🎯 Tujuan

Titik Temu dikembangkan sebagai konsep sistem pendukung keputusan kelompok berbasis web untuk membantu anggota kelompok menemukan alternatif kompromi berdasarkan preferensi dan batasan masing-masing.
